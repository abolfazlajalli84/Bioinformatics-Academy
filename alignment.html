دو الگوریتم کلاسیک بیوانفورماتیک را به‌صورت تعاملی اجرا کنید: Needleman-Wunsch برای هم‌ترازی سراسری و Smith-Waterman برای هم‌ترازی محلی. ماتریس امتیاز، مسیر بهینه و نتیجه‌ی نهایی را ببینید.

درک ریاضی و منطق پشت هم‌ترازی توالی‌ها

🧩 Needleman-Wunsch

الگوریتم برنامه‌ریزی پویا (Dynamic Programming) برای هم‌ترازی سراسری. کل طول دو توالی را پوشش می‌دهد و برای توالی‌های هم‌طول یا مشابه مناسب است.

F(i,j) = max {
  F(i-1,j-1) + s(xᵢ,yⱼ),
  F(i-1,j) + d,
  F(i,j-1) + d
}

🎯 Smith-Waterman

نسخه‌ی محلی الگوریتم. به‌جای پوشش کل توالی، بهترین ناحیه‌ی مشابه را پیدا می‌کند. برای یافتن دامنه‌های مشابه یا موتیف‌ها مناسب است.

F(i,j) = max {
  0,
  F(i-1,j-1) + s(xᵢ,yⱼ),
  F(i-1,j) + d,
  F(i,j-1) + d
}

📊 تفاوت کلیدی

سراسری: از گوشه‌ی ماتریس شروع و به گوشه‌ی مقابل می‌رسد. همه‌ی توالی در نظر گرفته می‌شود.

محلی: از هر نقطه‌ای می‌تواند شروع شود و به هر نقطه‌ای ختم شود. امتیازهای منفی صفر می‌شوند.
